# L2 асистент

Читає HP з екрана і **наводить курсор** на слоти F1 (атака) / F2 (наступна ціль). Клік робить макрос на миші. **F12** — стоп.

## Запуск

```bat
pip install -r requirements.txt
python ui.py
```

або `run.bat` (краще від адміністратора).

## Налаштування

1. Калібрувати HP цілі / моє HP  
2. **Наведення F1** / **Наведення F2** — клік по слоту (зберігається лише позиція)  
3. У миші: макрос «клік ЛКМ кожні ~0.5 с»  
4. Старт → фокус на гру. F12 — стоп
