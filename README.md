# L2 асистент

Невеликий асистент для Lineage 2 (сервер Scryde): зчитує смуги HP з екрана і натискає клавіші атаки / наступної цілі.

## Запуск на Windows

1. Встановіть [Python 3.10+](https://www.python.org/downloads/) (під час установки поставте галочку **Add Python to PATH**).
2. Відкрийте командний рядок у папці проєкту і встановіть залежності:

   ```bat
   pip install -r requirements.txt
   ```

3. Запустіть інтерфейс **від імені адміністратора**, щоб натискання клавіш доходили до гри і працювала глобальна F12:

   ```bat
   python ui.py
   ```

   (ПКМ по командному рядку або PowerShell → «Запуск від імені адміністратора», потім перейдіть у папку проєкту і виконайте команду.)

4. **Калібрування.** Натисніть «Калібрувати ціль» і натягніть напівпрозору рамку на смугу HP цілі (перетягніть тіло рамки, щоб перемістити; правий нижній кут — щоб змінити розмір). Enter або кнопка «Зберегти». Так само відкалібруйте «Калібрувати моє HP», якщо потрібен стоп за власним здоров’ям.
5. Після калібрування натисніть **Перевірити калібрування**: у вікні (оновлення кожні 0,5 с) видно збільшений знімок кожної смуги, які стовпчики розпізнані як червоні, і порахований HP%. Невідкалібрована область показує «не відкалібровано».
6. Перевірте клавіші та паузи в полях, натисніть **Старт**. **F12** або кнопка **Стоп** зупиняють бота.

Вікно завжди поверх інших. Налаштування зберігаються в `config.json` і підхоплюються при наступному запуску.

## Як це працює

Бот у фоновому потоці знімає вибрану ділянку екрана, рахує HP% як позицію крайнього правого «червоного» стовпчика смуги і:

- якщо цілі немає (0%) — натискає клавішу наступної цілі (типово F2);
- інакше — клавішу атаки (типово F1);
- між натисканнями чекає випадкову паузу в заданому діапазоні (типово 300–700 мс).

Зупиняється, якщо HP цілі не змінюється задану кількість секунд кілька разів поспіль, або якщо власне HP падає нижче порогу. Причина зупинки пишеться в журнал.

## Примітки

- Запускайте від адміністратора, інакше DirectInput / глобальна F12 можуть не працювати, поки гра в фокусі.
- Рамки калібрування мають закривати саме кольорову частину смуги HP, без підписів навколо.
- Не додає лут, бафи, хіл, зілля чи рух — лише атака / зміна цілі за HP на екрані.
