# L2 асистент

Асистент для Lineage 2: зчитує смуги HP з екрана і клікає по слотах панелі умінь (атака / наступна ціль).

## Запуск

1. Python 3.10+
2. `pip install -r requirements.txt`
3. `python ui.py` або `run.bat`

## Налаштування

1. **Калібрувати ціль** / **Калібрувати моє HP** — рамка на смугу HP.
2. **Клік атаки** / **Клік наступної цілі** — один клік по слоту на панелі.
3. **Перевірити калібрування** — чи правильно читається HP.
4. **Старт** → клікніть у вікно гри. **Стоп** — кнопка в асистенті.

Паузи між діями і стоп за власним HP налаштовуються в полях. Зберігається в `config.json`.

## Примітки

Деякі клієнти (наприклад Scryde) блокують програмні кліки. Тоді асистент лишається корисним для моніторингу HP; дії краще робити макросом на миші.
