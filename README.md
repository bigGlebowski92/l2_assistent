# L2 асистент

Читає HP з екрана, **наводить і клікає** F1 (атака) / F2 (наступна ціль) / F3 (якщо моє HP нижче порогу).  
Перед кожним кліком тисне **Space** (щоб «розморозити» софт-клік після руху курсора). Якщо Space з асистента не допомагає — увімкни макрос Ctrl на миші. **F12** — стоп.

## Запуск

```bat
pip install -r requirements.txt
python ui.py
```

або `run.bat` (краще від адміністратора).

## Налаштування

1. Калібрувати HP цілі / моє HP  
2. **Наведення F1** / **F2** / **F3** (хіл)  
3. **Поріг HP → F3 (%)** — якщо моє HP нижче, один клік F3 (0 = вимкнено)  
4. Старт → фокус на гру. F12 — стоп  

У `config.json`: `unstick_key` (true/false), `unstick_vk` (Space=`0x20`, Ctrl=`0x11`).
